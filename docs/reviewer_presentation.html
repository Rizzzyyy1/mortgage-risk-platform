Architecture & reproducibility controls

Reproducible by construction, not by convention

Engineering

Python orchestrates transparent calculations; DuckDB/SQL handles analytical aggregation; Parquet stores detailed outputs. Bounded, single-pass scans are reused across modules instead of re-ingesting.

Integrity controls

Every frozen artifact — model, features, labels, protocol — carries a SHA-256 fingerprint. A hash mismatch raises an error rather than silently reusing stale or substituted evidence.

Frozen protocols

Model-selection, calibration and final-evaluation criteria were written and hashed before each cohort's outcomes were read. No threshold was relaxed after seeing a result.

sh scripts/check_release.sh runs a dependency check, the full test suite, and a fresh vendor-free synthetic demo in one pass — and fails closed if any fingerprinted input has changed. No refit, recalibration or threshold change occurred after the final 2013Q1 evaluation was read.

AUC is discrimination, not accuracy

AUC is the chance the model ranks a randomly chosen defaulting loan above a randomly chosen non-defaulting loan — not a percentage of correct predictions. AUC 0.875 means that happens 87.5% of the time for the redeveloped candidate, versus 63.9% of the time for the historical benchmark on the same 2013Q1 cohort.

The redeveloped candidate reuses the original challenger's training population and predictors; it was reselected via a development-only comparison on 2011Q1 (the identical model resulted), then calibrated once on 2012Q1. The original challenger's failed evaluation remains an immutable, unaltered record.

Without vendor data

.venv/bin/python -m pip install -r requirements.lock .venv/bin/python -m pytest -q .venv/bin/python -m mortgage_risk.demo --output ...

Requires the private 2010Q1–2013Q1 files, not bundled in this package. Re-run the module referenced by each artifact directory in project_status.md / redevelopment_plan.md.
